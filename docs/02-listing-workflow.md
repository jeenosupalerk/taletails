# 02 — ขั้นตอนลงสินค้า (Listing Workflow)

## การลงสินค้าแบบ bulk จากรูปภาพ

แผนงาน: ลงสินค้าทีละหลายชิ้นโดยส่งไฟล์รูปการ์ดที่ตั้งชื่อไฟล์เข้ารหัสข้อมูลไว้ในชื่อไฟล์เอง แทนการกรอกฟอร์มทีละรายการ

### กฎการตั้งชื่อไฟล์

รูปแบบ: **`price_condition.jpg`**

| ตัวอย่างชื่อไฟล์ | ราคา | เกรด/condition |
| :---- | :---- | :---- |
| `500_10.jpg` | 500 | 10 |

### สิ่งที่ยังไม่ยืนยัน — ต้องตกลงให้ชัดก่อนสร้างระบบจริง

- ชื่อการ์ด (`name`) มาจากไหน — พิมพ์เองในชื่อไฟล์เพิ่ม, ใช้ชื่อไฟล์รูปเดิม, หรือให้ระบบ/AI อ่านจากภาพ
- `sale_type` (fixed_price/auction) กำหนดยังไงตอน bulk upload — เข้ารหัสในชื่อไฟล์เพิ่ม หรือเลือกทีเดียวทั้งชุดตอนอัปโหลด
- รองรับกรณีชื่อไฟล์ผิดรูปแบบ (ไม่มี `_` คั่น, ราคาไม่ใช่ตัวเลข ฯลฯ) อย่างไร
- อัปโหลดผ่านช่องทางไหน (หน้าเว็บ, สคริปต์, Supabase Storage โดยตรง)

> เติมรายละเอียดในไฟล์นี้ทันทีที่ตกลงกันแล้ว อย่าปล่อยให้ตกลงกันในแชทอย่างเดียว
