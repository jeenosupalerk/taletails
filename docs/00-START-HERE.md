### หน้า `/auctions`
- มีรอบเปิด → ห้องประมูลตามปกติ
- ไม่มีรอบเปิด + ยังไม่ล็อกอิน → กล่อง "ยังไม่มีประมูลเปิดอยู่ตอนนี้" + การ์ดในตลาด
- ไม่มีรอบเปิด + ล็อกอิน → กล่องเดียวกัน + ปุ่มเปิดแจ้งเตือน + ผลประมูลรอบที่ผ่านมา
- **ห้ามกลับไปใช้ข้อมูลตัวอย่างจาก `src/data/auctions.ts` แสดงเป็นประมูลจริงอีก** (เคยทำให้ผู้เยี่ยมชมเห็นประมูลปลอม)
- ร้าน**ยังไม่มีตารางเปิดรอบตายตัว** — อย่าเขียน "ทุกคืน 20:00" ในหน้าใหม่ (หน้าแรกกับบทความข่าวยังมีคำนี้อยู่ รอเจ้าของตัดสินใจ)
