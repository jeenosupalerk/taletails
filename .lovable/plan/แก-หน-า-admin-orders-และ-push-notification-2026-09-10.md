# แก้หน้า Admin Orders และ Push Notification

## สิ่งที่จะปรับ

- เพิ่มสถานะ `completed` ให้หน้า Admin Orders ทั้งชนิดข้อมูล ตัวกรอง ป้ายสถานะ และการแสดงวันที่รับสินค้า เพื่อไม่ให้หน้าล้มหลังลูกค้ายืนยันรับของ
- เพิ่มหน้าข้อผิดพลาดในรายการคำสั่งซื้อ เพื่อให้แอดมินเห็นสาเหตุและกดลองใหม่ได้แทนหน้าว่าง
- ทำให้ Web Push ใช้ Public Key จากเซิร์ฟเวอร์เป็นแหล่งเดียว เพื่อลดปัญหา Public/Private VAPID key ไม่ตรงกันระหว่าง Preview และเซิร์ฟเวอร์จริง
- ปรับคิว Push ให้ทำเครื่องหมายว่าส่งแล้วเฉพาะเมื่อส่งสำเร็จหรืออุปกรณ์หมดอายุ และเก็บรายการที่ส่งล้มเหลวไว้ลองใหม่ในรอบถัดไป
- ส่ง Push หลังลูกค้ายืนยันรับของและหลังแอดมินเปลี่ยนสถานะคำสั่งซื้อ โดยไม่ต้องรอรอบ Scheduled Task เพียงอย่างเดียว

## การตรวจสอบ

- ตรวจหน้า `/admin/orders` กับคำสั่งซื้อสถานะ `completed`
- ตรวจการเปิดรับแจ้งเตือนและ Test Push
- ตรวจคิวแจ้งเตือนค้างส่งว่าส่งซ้ำได้และไม่ถูกทำเครื่องหมายผิด
- ตรวจชนิดข้อมูลและการทำงานของ Preview หลังแก้

## รายละเอียดทางเทคนิค

- ไม่เพิ่มตารางหรือเปลี่ยน RLS
- ใช้ server function ที่มีการยืนยันตัวตนสำหรับอ่าน VAPID Public Key และส่งคิวทันที
- คง Scheduled Task `/api/public/push/dispatch` เป็นตัวสำรองสำหรับตอนผู้ใช้ปิดเว็บ
